YASHU SORATHIA — PORTFOLIO STARTER

Files:
- index.html: page content and sections
- style.css: colors, layout and responsive design
- script.js: mobile navigation and current year

HOW TO PREVIEW:
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html to preview it in your browser.
4. Edit the files using Visual Studio Code for easier editing.

IMPORTANT CUSTOMIZATION:
1. In index.html, replace YOUR-GITHUB-USERNAME with your actual GitHub username.
2. Replace YOUR-EMAIL@example.com with an email address you want to publish.
3. Check the education, experience and skills wording for accuracy.
4. The three project cards are ideas/placeholders, not completed projects. Keep them clearly marked until you build them.
5. Add real project links only after uploading the projects to GitHub.

PUBLISHING:
You can publish the finished website using GitHub Pages after creating a GitHub repository.
